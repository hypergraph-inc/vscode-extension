# Hypergraph

Embed the Hypergraph inside of VS Code.

Open your hypergraph in a sidebar, or as a main panel, or as multiple main panels.

This extension surfaces a running Hypergraph instance in a VS Code sidebar panel, letting you browse the ontological fabric without leaving your editor. Connect to a local or remote deployment and watch the network evolve in real-time.

## Examples

1. One pane for your source code, when your LLM edits a file you can ask it to mark what it will edit.

2. In another, perhaps you have a cute plant growing.

3. In your main panel: the algorithm currently being investigated, or observed.

4. A list of recent connections to your account, or an overview of your agents.

5. Concurrent algorithms running across two different sections of a hypergraph, viewed side-by-side simulteaneously.
